# Creator Autopilot v2

A runnable AI creator operating-system starter.

## Start
- Install Node.js 20+
- `npm install`
- copy `.env.example` to `.env`
- `npm start`
- visit http://localhost:3000

## v2 modules
Overview, AI Studio, Auto Planner, Calendar, Social Accounts and Settings.
API endpoints cover dashboard, posts, AI ideas/scripts/captions/plans, settings, connection state and publishing adapters.

## Important
The included AI endpoints are safe demo/template implementations. Setting `OPENAI_API_KEY` alone does not magically implement a production AI integration; add the current provider SDK/API call and validate outputs.

Social account buttons are connection-state demos. Real YouTube/Instagram/Facebook publishing needs each platform's official OAuth flow, permissions, token refresh, media upload and publishing API adapter. Add authentication, encrypted secrets, database, queue/worker, storage and monitoring before production.

No system can guarantee income; revenue depends on audience, content performance, platform rules and monetization eligibility.
